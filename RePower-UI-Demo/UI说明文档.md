# RePower-360 界面 Demo 说明文档

> 归属：《产品系统设计》设计任务书 2-1 ·「智储重生 RePower-360」工商业储能柜后市场方案
> 对应交付物：**交付物 2 —— 移动端或 PC 端界面 Demo（可录屏导出 MP4）**

---

## 一、总览：这套 UI 展示什么、要达成什么

本 Demo 用一套可交互网页，把「工商业储能柜后市场」这件看不见、摸不着的生意，**翻译成能源总监和运维工程师每天真的会打开的两个界面**：
一边是 **PC 中台（资产救援与收益管理）**，回答"我的储能柜现在健康吗、断网了吗、因为电芯木桶效应每个月白白损失多少钱、订阅服务值不值"；
另一边是 **移动端 App（现场作业与电池护照）**，回答"工程师到了柜子前该连什么、给哪颗电芯注入多大电流、温度异常怎么办、退役的电池还能卖多少钱"。
PC 端与移动端共用同一套工业深色 CMF（石墨灰 + 琥珀状态灯 + 急停红），与硬件 Re-Pulse / Re-Bridge 同源，**总目标只有一个：让"重制造、轻运维"的行业现状，在界面上第一次变得可看、可算、可派单、可变现**——把后市场从"坏了才修"呈现为"资产运营"。

## 三、PC 中台：五个模块

### 1. 资产救援大盘（DASH）
- **顶部 KPI**：在管储能柜 10 座、网关在线率 80%、孤儿电站 2 座、本月挽回电价收益 ¥31,420、待派/进行中工单 2 单。
- **储能柜资产台账**：10 座站点（浙/苏/粤 6 个园区）逐条列出柜号、规格（100kW/215kWh ~ 125kW/261kWh）、状态灯（在线 / 健康告警 / 孤儿电站 / 活化作业中 / 待退役评估）、整柜 SOH 进度条、簇间压差 ΔV、月损失金额；断网站提供「重新上云」按钮，在线柜提供「查看孪生」跳转。
- **AI 预警塔**：5 条提前 15 天的预警事件流（断网判定、PACK-03 内阻抬升、SOH 极差 13.8%、液冷电导率上升、套利收益低于基线）。
- **今日峰谷套利**：00–24 时六时段收益柱状图，直观显示两充两放形成的收益峰。
- **全生命周期闭环**：重新上云 → 季度订阅 → 主动维护 → 回收转卖 四段流程条。
- **可交互**：单柜「重新上云」会弹出网关铺设四步说明并**真实改写该站点状态**；「批量重新上云」生成 2 张工单；点击台站可跳转到该柜的数字孪生。

### 2. 电芯数字孪生（240 颗单体）
- **SOH 热力矩阵**：5 个 PACK × 48 颗 = 240 颗电芯色块矩阵（红→琥珀→绿映射 SOH 58%~96%），PACK-03 为落后簇；悬停查看单体参数，点击弹出详情 Toast（SOH / 电压 / 温度 / 内阻），可切换 10 座柜查看。
- **关键指标**：平均 SOH、簇间极差（13.8%，即"木桶效应"）、落后单体数量（8 颗，最弱 66.2%）。
- **两张分析图**：SOH 分布直方图；簇间压差 ΔV 的 15 天预测曲线（不干预 vs 主动活化后 vs BMS 均衡极限）。
- **落后单体清单 + 修复前后对比**：列出 Top 8 短板单体（SOH / 电压 / 内阻），并给出修复后可放电量、作业时长 ≈2 小时、预计月增收益。
- **可交互**：「下发 5~10A 靶向活化作业」生成工单并跳转移动端作业页。

### 3. 经济收益晴雨表（ROI · 整页单柜年化口径，全联动）
> 本页所有数字同宗同源：**下方两个滑块是唯一的参数源**，拖动后 KPI、收益明细与两张图表同步重算，不存在"局部动、其余不动"的孤岛数据。

- **客户算一算（参数源）**：每日少放电量（5~45 kWh）、峰谷价差（0.40~1.30 元/度）两个滑块；输出单柜年损失电费与两种 ROI。
- **方案切换（参数源 ①）**：卡内「基础版 · 2499/季（封顶）」与「分成版 · 1499/季 + 分成」两个按钮，切换后整页按该档价格构成重算 —— 基础版：服务支出 ¥9,996、直接 ROI 106%、综合 ROI 162%、回收 7.4 个月；分成版：服务支出 ¥8,636（固定 5,996 + 分成 2,640）、ROI 122% / 187%、回收 6.4 个月。
- **四个 KPI（随方案 + 滑块联动）**：**采用方案后净收益 / 柜 / 年**、**单柜年服务支出（档位名 + 价格构成）**、直接电费 ROI、综合 ROI（含残值溢价与延寿），回本月数同步改写。单柜年损失电费不占 KPI，而在左侧测算卡中以大红数字呈现（默认 ¥10,560）。
- **收益明细（随滑块联动）**：① 峰谷套利挽回 ② 梯次残值溢价 ③ 延寿/免提前换包 − 年度订阅成本 = 净收益/柜/年。
- **图 1 · 单柜月度挽回 vs 订阅投入**：把年化收益摊平到 12 个月（挽回柱 / 订阅柱）+ 累计净收益折线，随滑块重算。
- **图 2 · 单柜累计净收益与回本点**：24 个月累计曲线，零轴与"回本 ≈ N 个月"标注线随滑块移动（如 20kWh/0.80 元时 ≈7.4 个月，40kWh/1.30 元时 ≈3 个月）。
- **组合口径补充**（静态注释，不参与联动）：签约托管 150 柜后，初创团队预计第 14~18 个月整体收支平衡。

### 4. 工单与订阅（SLA）
- **作业工单台账**：6 张工单（工单号 / 站点 / 作业类型 / 责任人 / SLA 状态），待派单可「立即派单」并弹窗显示推荐工程师与预计到达时间；作业中可跳转 App 实时作业。
- **今日作业负荷 + SLA 承诺看板**：浙北/浙东/广深三组工程师派单分布；云端告警 ≤60 秒、上门响应 ≤2 小时（两档订阅一致）。
- **两档订阅方案（服务内容完全一致，只在价格构成上二选一）**：
  - **基础版 · 固定订阅**：2,499 元 / 柜 / 季（折合 9,996 元 / 年），费用封顶、预算可预测。
  - **分成版 · 增量分成（主推）**：1,499 元 / 柜 / 季（固定服务费较基础版 ↓40%）+ 修复后增量套利收益 **20%~30%** 分成，未达承诺的 8% 恢复量则不收分成部分。
  - 两档均含：断网重连与云端预警、季度上门 5~10A 主动均衡活化、承诺放电可用容量恢复 ≥8%、SOH 报告与电池护照优先出具，均可一键开通。

### 5. 电池护照与梯次转卖
- **储能电池身份证**：SOH 76.8% 仪表盘 + Grade A 评级，资编号 / 累计循环 2841 次 / 剩余可用 165.2 kWh / 簇间 ΔV 36mV / 27 个月数据溯源。
- **残值对比**：黑粉废铁回收价 ¥9,800 vs 梯次撮合成交价 ¥42,300，业主多挽回 ¥32,500，平台佣金 8%（¥3,384）。
- **全生命周期数据链**：2024-05 上云 → 首次活化 → 连续 SOH 报告 → 触发退役评估 → 出具护照挂牌 五段时间轴。
- **梯次降级去向**：Grade A（75%~80% → 叉车/低速车电池）、B（70%~75% → 离网微网/灌溉）、C（<70% → 拆解再生）三档价格与占比。
- **可交互**：「出具护照并挂牌」弹出 5 家下游厂商报价表（¥40,100 ~ ¥44,200），确认后完成挂牌撮合。

## 四、移动端 App：四个主屏 + 安全浮层

| 屏幕 | 展示内容 | 关键交互 |
| --- | --- | --- |
| **首页 · 今日作业** | 主任务卡（ESS-ZJ-003 杭州湾精细化工 B1 柜、落后单体 P03-014 SOH 66.2%、工时 118 分钟）、我的装备（Re-Bridge / Re-Pulse 电量与链路）、云端 AI 预警、昨日挽回容量 11.4% 与月增收益 ¥2,614 | 进入作业流 / 去扫码 |
| **扫码连接** | 扫码取景框（扫描线动效）→ 连接成功卡：私有 CAN 协议已破解、4G Cat-1 RSSI −78dBm、240/240 单体建档、拟作业对象 PACK-03 ΔV 41mV | 模拟扫码成功 → 开始靶向活化 → 断开连接 |
| **活化作业流** | 簇间压差 ΔV 大数字实时回落（41 → 12mV）、注入电流 8.4A、最高单体温度、已挽回容量；四步作业指引阶梯（开仓接线 → 定位落后单体 → 注入 5~10A → 复核 ΔV<12mV）；落后单体定位导航（#007/#014/#021/#028/#035/#042/#048）与探针适配说明 | 开始/暂停活化（进度条动画，约 16 秒跑完）→ 作业完成卡（挽回 11.4%、耗时 116min、月增 ¥2,614）→ 工单自动回填 |
| **电池护照与转卖** | SOH 76.8% + Grade A、评估价区间、废铁价对比与残值溢价、27 个月数据溯源与年均衰减 3.6%、两项发布勾选项 | 勾选评估与 8% 佣金协议 → 一键挂牌 → 5 家厂商收到报价邀请 |

- **温度异常安全浮层**（独立叠加层）：单体 52.4℃ 超阈值 45℃ 时自动降流并弹出五步处置指引（停止注入 → 检查极柱 → 开门通风 → 必要时按下 Re-Pulse 红色急停蘑菇头 → 写入日志），可「降流继续作业」或「急停并中止作业」。
- **右侧解说栏**：逐屏标注该界面对应的任务书要求，并给出 60 秒录屏建议顺序。

## 六、演示与出图

**操作路径**：双击 `index.html` → 顶部切换「PC 中台 / 移动端 App」→ 点击左侧导航或底部 Tab 浏览各屏 → 点击按钮触发交互。

**建议录屏顺序（60 秒内，导出 MP4 随作业包提交）**：
大盘（点一次「重新上云」）→ 数字孪生（悬停色块、下发工单）→ 收益晴雨表（拖动滑块）→ 移动端扫码 → 活化作业（跑进度条 + 触发一次温度告警）→ 电池护照挂牌。

**深链（便于定点截屏 / 分段录制）**：

| URL | 直达 |
| --- | --- |
| `index.html#pc-dash?shot=1` | PC · 资产救援大盘（出图模式） |
| `index.html#pc-twin?shot=1` | PC · 电芯数字孪生（出图模式） |
| `index.html#app-job?shot=1` | 移动端 · 活化作业流（仅手机机模） |
| `index.html#app-home` / `#app-scan` / `#app-pass` | 移动端其余主屏（保留演示条） |

`?shot=1` 会隐藏顶部演示条、右侧解说栏与开场弹窗，只保留界面本体。
